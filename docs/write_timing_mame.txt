# Cisco Heat MAME write timing

Runs use MAME 0.289 and 1,800 measured frames after the configured skip. The play run inserts coin at frame 600.

"vblank start 14" below is where MAME's frame notifier runs. Cisco Heat sets
VIDEO_UPDATE_AFTER_VBLANK (cischeat.cpp:1777), so that is vblank END, the point MAME draws the
frame and reads the sprite list and scroll registers; the "vblank" column is therefore not
vblank. Read the columns as measured from MAME's draw point. The sprite strip is flat: the game
writes sprite RAM through the whole frame.
